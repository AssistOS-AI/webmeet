webmeet

Ploinky agents for WebMeet rooms, the LiveKit media runtime, the optional Meeting Secretary and speech-to-text. Agent identities are agent:webmeet/<agent>. Each agent keeps its own documentation.

The shared module documentation-breadcrumb.js in this directory is imported by the per-agent docs/partials-loader.js files. Test commands and cross-repository rules are in AGENTS.md.
