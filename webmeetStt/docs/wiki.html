WebMeet STT terminology

WebMeet STT

WebMeet STT is the speech-to-text service used by WebMeet media workflows that require server-side transcription. It accepts the configured media stream contract, produces transcript events, and remains separate from WebMeet's room storage and browser-only speech-recognition shortcut.

Model Context Protocol

Model Context Protocol is the configured tool boundary used by the agent. Tool names and input schemas come from the local MCP configuration and execution remains subject to the agent's verified runtime authorization.

Ploinky

Ploinky starts the agent, supplies its runtime environment, and mediates authenticated invocation context. The agent does not treat client-declared identity as authorization.

STT

Speech to text (STT) converts accepted audio into transcript text. The STT service owns transcription processing; WebMeet decides how an authorized room workflow consumes the resulting transcript.

Media boundary

The media boundary separates ephemeral audio transport and transcription from durable room records. The STT service does not become the source of room membership, chat history, or Meeting Notes persistence.
