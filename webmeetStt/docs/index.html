webmeetStt

Internal Faster-Whisper speech-to-text service for WebMeet scribe agents, with optional self-hosted DTLN denoise before transcription. The start-only container remains on its isolated Ploinky default network, publishes no ports, and declares an in-container /healthz probe for private port 9000. Explorer launches STT as a detached no-wait dependency, so STT health does not gate Explorer startup.
