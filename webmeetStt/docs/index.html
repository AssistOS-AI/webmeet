webmeetStt

Internal Faster-Whisper speech-to-text service for WebMeet scribe agents, with optional self-hosted DTLN denoise before transcription.

The Ploinky manifest uses one isolated bridge attachment named webmeet; it declares no browser HTTP service or physical-host publication. Its in-container readiness probe verifies the loopback /healthz endpoint without adding a Router target or port mapping.

Pinned Python dependencies are installed atomically into the persistent service data volume, retried up to three times on a cold install, and reused on later launches. Installer failures remain visible in the container log.
